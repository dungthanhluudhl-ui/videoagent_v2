# references/

References are lazy-loaded. Historical/reference files are not a mandatory
reading bundle for every video. Start from SKILL.md and open only the topic that
applies; code and each script's `--help` remain mechanical truth.

| File | Read when |
|---|---|
| `visual-language.md` | When choosing how to represent narration |
| `worked-examples.md` | When a difficult editorial transformation needs examples |
| `primitives.md` | While implementing a component; check existing capability first |
| `animation-variants.md` | While choosing or implementing motion |
| `gates.md` | Troubleshooting enforcement or locating a gate |
| `lessons.md` | Search for a relevant historical defect; do not read as a ritual |
| `kickoff-prompt.md` | Minimal user launcher for a fresh session |

`example-scene.jsx` was removed: a synthetic template drifts out of sync with
the real code. Copy patterns from the current `src/scenes/` instead — it is
proven, working code.
